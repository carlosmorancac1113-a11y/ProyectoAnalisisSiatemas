🛠️ Sistema Help Desk con n8n
📌 Descripción

Este proyecto consiste en el desarrollo de un sistema de mesa de ayuda (Help Desk) automatizado utilizando n8n.
Permite gestionar tickets de soporte técnico de forma organizada, desde su creación hasta su cierre.
El sistema centraliza la información y mejora la eficiencia en la atención de solicitudes.

🎯 Objetivo

Implementar un sistema automatizado que permita:

Registrar tickets de soporte
Dar seguimiento a solicitudes
Notificar al administrador
Gestionar el estado de cada ticket
⚙️ Tecnologías utilizadas
n8n (automatización de workflows)
MySQL (base de datos)
Gmail (notificaciones)
HTML/CSS (formulario web y dashboard)
🔄 Funcionamiento del sistema
🧩 Workflow 1: Registro de tickets
Recepción de datos desde un formulario web (Webhook)
Validación de información
Almacenamiento en base de datos (MySQL)
Envío de correo de confirmación (Gmail)
🧩 Workflow 2: Procesamiento de tickets
Ejecución automática cada 5 minutos
Consulta de tickets pendientes
Notificación al administrador
Actualización del estado del ticket
📊 Características principales
Automatización del flujo de tickets
Centralización de la información
Notificaciones automáticas
Seguimiento del estado de solicitudes
Interfaz básica para visualización
🚧 Limitaciones
No cuenta con sistema de usuarios o roles
Seguridad básica
Algunas funciones son visuales (no completamente automatizadas)
